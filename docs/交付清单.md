## 快速运行

```bash
# 主页面：可直接双击，或
python3 -m http.server 8000
# http://localhost:8000/index.html

# 测试页
# http://localhost:8000/test.html
```

测试页需要本地 HTTP 服务器以通过同源 iframe 访问主页面；主页面本身可直接 `file://` 打开。
