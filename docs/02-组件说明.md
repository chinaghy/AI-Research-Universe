# 可运行组件说明

## 1. 它是什么

“AI 科研知识宇宙”是一个**零构建、零后端的静态可视化组件**：由一个 HTML 入口、一个 CSS 视觉系统、一个 Canvas/Anime.js 渲染器、一份数据包和本地 vendor 组成。它不是某个框架里的半成品，而是可以直接打开、也可以被 iframe / 静态站点集成的完整组件。

## 2. 运行

```bash
# 方式一：直接打开
open index.html

# 方式二：推荐，尤其要运行 test.html
python3 -m http.server 8000
# http://localhost:8000/index.html
```

不需要 npm install、不需要打包、不需要联网。`vendor/anime.min.js`、`vendor/fonts/` 均已本地化。

> `test.html` 需要同源 iframe 访问，请使用本地服务器；直接 `file://` 打开时浏览器可能阻止测试页读取 iframe 内容。

## 3. 文件职责

```text
index.html          页面骨架、四个视图、HUD、时间轴、详情、洞察覆盖层
css/style.css       深空视觉、布局、响应式、面板与图表
js/app.js           Canvas 渲染、状态机、交互命中、Anime.js 时间线
js/data.js          945 篇论文 + hist + 9,111 条引用 + 国家/洞察/陆地点阵
vendor/anime.min.js Anime.js v4.0.2
vendor/fonts/       Space Grotesk
shots/              展示截图
test.html           交互验收台（8 项自动测试）
```

## 4. 组件边界

| 层 | 入口 | 可替换性 |
| --- | --- | --- |
| 数据层 | `window.AI_DATA`（`js/data.js`） | 可替换为同结构数据包 |
| 渲染层 | `js/app.js` 的 Canvas 投影与场景函数 | 可独立改视觉/布局 |
| 动效层 | Anime.js v4 | 可替换缓动或时间线 |
| 页面层 | `index.html` / `css/style.css` | 可嵌入静态站点或 iframe |

### 数据契约

`js/data.js` 暴露 `window.AI_DATA`，核心字段：

```js
{
  meta: { works, citations, countries, edges, fieldCounts, yearMin, yearMax },
  themes: {
    language: { name, color, count, top: [...], years: {...}, ... },
    // vision / generative / agents / science / trust / foundations
  },
  works: [{
    i, id, title, year, cites, theme, doi, abs, authors, countries,
    hist: [/* 2012—2025 年逐年被引 */], pos: [x, y, z]
  }],
  edges: [[citingIndex, citedIndex], ...],     // 主画布代表边
  allEdges: [[citingIndex, citedIndex], ...],  // 完整邻接
  countries: [{ code, zh, en, lon, lat, count, themes }],
  collab: [[countryA, countryB, count]],
  insights: { growth, bridges, matrix, fieldSeries, ... },
  landDots: [[lon, lat], ...]
}
```

### 公开调试 / 测试 API

页面暴露 `window.__GALAXY__`，供 test.html 与二次开发使用：

```js
__GALAXY__.state              // 当前视图、年份、点亮模式、面板状态
__GALAXY__.camera             // 星系相机
__GALAXY__.globe              // 地球 yaw / pitch / zoom / locked
__GALAXY__.flow               // 知识流节点与弧线
__GALAXY__.setView('flows')   // galaxy / countries / flows
__GALAXY__.setYear(2017, false)
__GALAXY__.setLightMode('citation') // publish / citation
__GALAXY__.selectPaper(i)
__GALAXY__.selectCountry('GB')
__GALAXY__.selectFlowEdge('language', 'vision')
__GALAXY__.openInsights()
```

## 5. 集成方式

### 方式 A：作为整页组件

直接把 `index.html` 与 `css/`、`js/`、`vendor/` 以相同相对路径部署到静态服务器。适合课程展示、展览 kiosk。

### 方式 B：iframe 嵌入

```html
<iframe src="/ai-universe/index.html"
        style="width:100%;height:100vh;border:0"
        title="AI 科研知识宇宙"></iframe>
```

iframe 方式无需改动原组件；`test.html` 本身也使用这种方式。

## 6. 定制指南

- **换主题色**：修改 `js/data.js` 中 `themes.*.color`，并同步 CSS 中对应变量（或直接使用数据色）。
- **换数据**：保持 `works / themes / edges / countries / insights` 结构；重新生成 `js/data.js`。
- **换强调色**：修改 `css/style.css` 顶部 `:root` 变量。
- **关闭自动旋转**：在国家网络右下角点「锁定自转」；初始状态由 `globe.locked` 控制。
- **换默认时间语义**：初始化 `state.lightMode = 'publish' | 'citation'`。
- **改默认年份**：`state.year` 初始为 `D.meta.yearMax`，可改为其他年份。

## 7. 浏览器与性能

- 目标：Chrome / Edge / Safari 现代版本。
- 1440×900 下以 Canvas 2D 渲染 945 个星点、1,500 条代表边、3,455 个陆地点阵；本机帧率采样在 60fps 量级。
- 主画布只画代表边；完整 9,111 条边保留给悬停/详情。
- 标题使用实色回退，避免 `background-clip:text` 在部分渲染环境中导致整行透明。
- 响应式：1440 / 1024 / 768 / 390 四档。

## 8. 已知限制

- 主题聚类是策展规则，不是官方分类；
- 引用统计截止 2025 年；
- 国家取第一作者首个机构；
- RCA 在样本较小时只作方向观察；
- 星系位置为叙事布局，不是 UMAP。
